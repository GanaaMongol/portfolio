# Intent: Бизнесийн хамтрагчдад зориулсан portfolio вэб
Author: Owner. Status: draft. Date: 2026-11-17
Source: idea

## Асуудал (Problem)
"Би шууд вэб дээр байршуулах portfolio хэрэгтэй байгаа, бусад бизнесийн хамтрагчдад явуулах юм."
Одоогоор хамтрагчдад өөрийгөө, хийсэн ажлаа танилцуулах нэг холбоос (URL) байхгүй.

## Хүссэн үр дүн (Proposed outcome)
Хамтрагч нэг холбоос нээгээд 1 минутын дотор: хэн бэ, юу хийдэг вэ, ямар ажил хийж байсан бэ,
яаж холбогдох вэ гэдгийг ойлгоно. Утас болон компьютер дээр адилхан сайн харагдана.

## Нөлөөлөх хэрэглэгч ба систем (Affected users and systems)
- Бизнесийн хамтрагчид (монгол болон гадаад) — холбоосыг имэйл, мессежээр хүлээн авна.
- Owner — агуулгаа өөрөө засаж шинэчилнэ.

## Хязгаарлалт (Constraints)
- Шууд вэбэд байршуулах боломжтой байх (static hosting: Vercel / Netlify / GitHub Pages).
- Сервер, өгөгдлийн сан, нууц түлхүүр шаардахгүй.
- Агуулгыг код мэдэхгүй ч засаж болохуйц нэг файлд төвлөрүүлэх.

## Хамрах хүрээнээс гадуур (Out of scope)
- Блог, CMS, админ самбар, холбоо барих форм (сервер шаардана).
- Monitoring/band-watch, agent eval suite (static сайтад хэрэггүй).

## Амжилтын шалгуур (Success measures)
- Нийтэд нээлттэй URL ажиллаж байна.
- Lighthouse Performance/Accessibility ≥ 90 (mobile).
- Хамтрагч холбоо барих мэдээллийг нэг товшилтоор олно.
