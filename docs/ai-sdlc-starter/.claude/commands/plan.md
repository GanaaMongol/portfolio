description: Build an implementation plan from an approved spec (use in plan mode)
argument-hint: <intent folder>
---
Read $ARGUMENTS/intent.md and $ARGUMENTS/spec.md. Produce an implementation plan that
names the files that change, the order of work, the risks, and the tests that prove it.
Then tell me what this change could break, which step is riskiest, and which
alternatives you rejected. When I approve, save it as $ARGUMENTS/plan.md.
